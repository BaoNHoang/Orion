# Orion roadmap

## MVP stabilization

- Harden continuous voice sessions and wake-word behaviour.
- Complete responsive conversation, workspace, memory, research, and council flows.
- Add automated API and browser regression coverage.
- Add local backup and restore for user-owned data.

## Personal operator

- Add reminders and opt-in proactive notifications.
- Add consent-scoped local file and application tools.
- Improve memory review, correction, expiry, and sensitive-data controls.
- Add workspace summaries and selective context retrieval.

## Provider expansion

- Add OpenAI as an optional model and voice provider.
- Introduce provider routing by complexity, privacy, latency, and cost.
- Add token and usage telemetry without storing private prompt content.
- Keep Ollama as the offline and local-first path.

## Council evolution

- Make council membership, roles, and personalities configurable.
- Add evidence-aware deliberation and disagreement tracking.
- Persist multiple council sessions per conversation.
- Evaluate decision quality, latency, and resource use.

## Distribution

- Complete installable PWA validation on Windows and mobile.
- Add signed desktop packaging only after the web application is stable.
- Prepare migration from single-user local storage to encrypted sync when multi-device support begins.
