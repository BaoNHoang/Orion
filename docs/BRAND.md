# Orion brand asset

`public/orion-logo.svg` is an original vector mark created for this project on 2026-08-02. It uses project-authored geometric paths and does not reuse the path data from the Lucide `Orbit` icon that inspired the early interface direction.

The mark represents an orbital command ring, a connected reasoning core, and four decision nodes. Its primary colours are:

- Command background: `#10181d`
- Orion mint: `#90ead6`
- Orbit teal: `#76d7c1`

Lucide icons remain in the application interface under Lucide's ISC license, but they are not the Orion brand mark.

This provenance note documents project history; it is not a trademark clearance opinion.
